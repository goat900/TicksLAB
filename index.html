Tutorials
1. Start here

TickLab runs on a simulated market with a fake $1,000 balance. Nothing connects to a real account. Use Manual to place one trade, Auto for rule-based trading, and Builder to design your own rules.

2. Contract types and payouts

Even/Odd and Rise/Fall win about 50% of the time. Over/Under wins based on the digit you pick (Over 4 is 50%, Over 8 is 10%). Matches wins 10% and Differs 90%. Every payout is set so the average return is 95% of the stake, so over time you lose about 5 cents per dollar staked.

3. Reading the scanner

Tap the AI button to open the analyzer. It counts past digits and compares them with the expected percentage. A gap inside the stated range is normal randomness. Even a gap outside it does not make the next digit more likely.

4. Martingale and risk

Multiplying the stake after a loss only changes how losses arrive. At $1 with x2, five losses in a row cost $31 and a sixth would need $32 more. Cap the steps, keep a stop loss, and set the stake as a small percent of your balance. The Risk tab shows how many losses in a row you can survive.

5. Using the Auto Trader

Pick a rule, set the threshold, stake, take profit and stop loss, then Start. Presets load common setups. Alternate and Recovery options change which side it trades after a trade or loss, not the odds.

6. Using the Builder

Set the trade type, add purchase conditions (the first true one buys), then set martingale and stop limits. Export gives you a bot file you can save. Paste it back and press Load to restore it.

7. Before using a real account

Practice on Deriv's demo account first. Use a token with only the trade permission, never share it, and set a loss limit you can afford before you start. Never trade money you can't afford to lose.
